Artificial intelligence (AI) tools can support your learning while you build games with SplashKit. Use AI as a learning assistant, not as a replacement for your own problem-solving, coding, testing, and creativity. AI responses can be incorrect or incomplete, so check suggestions against your code, the [SplashKit documentation](/), and your own tests.

## What Can AI Help With?

AI can help you brainstorm game ideas, break tasks into steps, explain C++ and SplashKit concepts, suggest code for a feature, and investigate errors. It may misunderstand your requirements or suggest code that does not work with your project or SplashKit setup. Give it enough context, then verify its suggestions.

## Example Prompts

### 1. Generate a Game Idea

> Give me 5 beginner game ideas using SplashKit in C++. For each idea, describe the objective, controls, and one simple mechanic. Keep the ideas suitable for someone who is still learning programming.

Ideas might include a maze, a space shooter, a bouncing-ball game, or a simple platform game. Choose one with only a few mechanics to start.

### 2. Understand a SplashKit Function

> I am a beginner learning C++ with SplashKit. Explain how `draw_circle` works. Describe its parameters, how the x and y coordinates work, how the radius changes the circle's size, and how to choose a colour. Show a small example and explain each line without adding unnecessary concepts.

Compare the explanation with the [Draw Circle documentation](/api/graphics/#draw-circle).

### 3. Investigate an Error

> I am using SplashKit with C++ and VS Code. I am getting an includePath error when I include SplashKit. Explain what this error usually means, what settings I should check, and how I can verify a fix. Please do not rewrite my entire project.

For more useful help, include the exact error message and a small, relevant section of code. Remove passwords, access tokens, and other private information before sharing code or files.

### 4. Plan with Pseudocode

> I am a beginner making a bouncing-ball game with SplashKit in C++. Help me plan before writing code. Explain which variables I might need, how the ball moves and bounces off the window edges, and how the game loop works. Give me pseudocode and explain each step. Do not write the complete game for me.

### 5. Build One Feature at a Time

> I am making a simple game with SplashKit in C++. Help me add a player character that moves left and right. Explain the steps, show only the relevant code, and suggest a small test. Do not add other features yet.

Once that feature works, ask for help with the next one.

## How Long Might Planning Take?

As a rough estimate, planning a small beginner game might take an hour or two. The time will vary with your experience and how many rules or features you want to include; treat this as a starting point, not a deadline.

## Build the Game Yourself

AI can help with many parts of game development, but you should not expect it to produce a complete, working game without your involvement. Plan the game, implement it a feature at a time, and test as you go. You are responsible for understanding the code and checking that the game works as intended.

A good prompt explains what you are trying to achieve, what is happening instead, the tools or language you are using, and what kind of help you want.

**Bad prompt:**

> Fix my SplashKit code.

**Better prompt:**

> I am using SplashKit in C++. My goal is to draw a circle in a window, but the window closes immediately. Explain why this may happen and suggest a fix without rewriting the whole program. Tell me what to test after making the change.

## A Simple Game Development Roadmap

1. Choose a small game idea and write down its objective, controls, and rules.
2. Set up a window and draw the game objects.
3. Add movement and player controls.
4. Add essential rules, such as collisions or scoring.
5. Test each feature and fix problems.
6. Improve the game after the basic version works.

A small, finished game is a worthwhile achievement. You do not need to add every possible feature.

## If AI Cannot Solve the Problem

AI may not identify the right solution. If you are stuck:

1. Read the error message carefully.
2. Check the relevant [SplashKit documentation](/).
3. Review your code and try to reproduce the problem with a smaller example.
4. Ask a teacher, tutor, or another developer for help.

Use AI alongside documentation, testing, and help from other people—not as your only resource.

## Use AI Responsibly

- Use AI to learn concepts, brainstorm, and get explanations.
- Break large tasks into smaller steps.
- Verify AI-generated code and test it in your own project.
- Follow your course or institution's AI guidelines.
- Acknowledge AI assistance when required.
- Do not submit AI-generated work as your own or rely on code you do not understand.

## Final Checklist

Before using AI-generated ideas or code, ask yourself:

- Do I understand how it works?
- Can I explain it to someone else?
- Have I tested it myself?
- Does it follow SplashKit style guidelines?
- Have I followed the AI-use rules for my course?

If you can answer these questions, you are taking an active and responsible approach to learning.

Happy learning with SplashKit and AI!
