# Frequently Asked Questions (FAQ)

Welcome to the SplashKit Website team! This FAQ answers some of the most common questions new contributors have when getting started.



## How do I get started?

Before contributing, make sure you have completed the project setup:

- Install Git, Docker, Node.js and VS Code.
- Fork and clone the SplashKit Website repository.
- Open the project in a Dev Container.
- Run `npm install`.
- Start the development server using `npm run dev`.



## How do I choose a task?

Open the Planner board and select an unassigned task.

Before starting:
- Assign the task to yourself.
- Move the task to **In Progress**.
- Read the task description and acceptance criteria carefully.



## What if someone is already working on a task?

Please avoid working on a task that has already been assigned unless you have discussed it with the contributor or the team lead. This helps prevent duplicate work and merge conflicts.



## How should I create a branch?

Create a separate branch for every task using a meaningful name.

**Example:**

- `docs/new-contributor-faq`
- `feature/rectangle-intersection-example`



## What should I do before opening a Pull Request?

Before creating a Pull Request, make sure you have:

- Tested your changes locally.
- Reviewed your code or documentation.
- Removed any unrelated changes.
- Completed the Pull Request template.
- Linked the relevant Planner task or GitHub issue.



## What should I do if I receive review comments?

Code reviews are part of the development process.

When you receive feedback:

- Read every comment carefully.
- Make the requested changes.
- Reply to comments once they have been addressed.
- Push your updates.
- Re-request a review.

Remember, feedback is intended to improve the quality of the project.



## What should I do if I get stuck?

If you're unsure about something:

- Check the project documentation.
- Review the [SplashKit Troubleshooting Guide](/troubleshoot/).
- Ask questions in the team channel.
- Reach out to your Team Lead.

It's always better to ask early than stay blocked.



## How do I keep the Planner board updated?

Update your task as you progress:

- **To Do** → Task is available
- **In Progress** → You're actively working on it
- **In Review** → Pull Request has been submitted
- **Done** → Changes have been approved and merged

Keeping the board updated helps everyone understand the team's progress.



## Can I work on multiple tasks at the same time?

It is recommended to complete one task before starting another. This keeps Pull Requests focused and makes reviews much easier.



## What if I accidentally modify unrelated files?

Before committing your changes:

- Review the modified files.
- Remove any unrelated changes.
- Ensure your Pull Request only contains files related to your assigned task.

A clean Pull Request is easier to review and merge.



## Where can I find more help?

Useful resources include:

- [SplashKit Troubleshooting Guide](/troubleshoot/)
- [SplashKit Website GitHub Repository](https://github.com/thoth-tech/splashkit.io-starlight)

For questions about task selection, Pull Requests, peer reviews, or the Planner board, reach out to your Team Lead or ask in the team communication channel.

If you still need assistance, don't hesitate to ask the team.
